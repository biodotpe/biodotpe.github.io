# Video Tutorials
 
Step-by-step video tutorials on open-source hardware documentation, published on YouTube by the **LIBRE hub**.
 
> 🌐 The videos are presented in **Spanish**. English subtitles and automatic translation are available in YouTube's settings (⚙️ → Subtitles/CC → Auto-translate).
 
---
 
## GitBuilding
 
Learn how to document open-source hardware with [GitBuilding](https://gitbuilding.io): what it is, how to install it and how to create your first project. All steps are demonstrated on Windows 11.
 
▶️ **[Watch the full playlist](https://www.youtube.com/playlist?list=PLQFiqig0NTkNnxiLbt9qHvOctbcvWUpuz)**
 
### 1. Open Documentation with GitBuilding
 
[![Open Documentation with GitBuilding](https://img.youtube.com/vi/c9-XIyGD_-8/hqdefault.jpg)](https://youtu.be/c9-XIyGD_-8)
 
An introduction to open documentation and to what GitBuilding can do for your hardware projects.
 
### 2. Installation of GitBuilding
 
[![Installation of GitBuilding](https://img.youtube.com/vi/4lanRiFEUd0/hqdefault.jpg)](https://youtu.be/4lanRiFEUd0)
 
How to install GitBuilding and get it running on your computer.
 
### 3. Create a GitBuilding Project from Scratch
 
[![Create a GitBuilding project from scratch](https://img.youtube.com/vi/LiVoCksC7Ug/hqdefault.jpg)](https://youtu.be/LiVoCksC7Ug)
 
A hands-on walkthrough of creating a new GitBuilding project from zero.
 
> These videos are a community contribution and are not official GitBuilding tutorials.
